# Sources and scope

[Back to LinkedIn Content to Pipeline](../README.md)

LinkedIn Content to Pipeline is a standalone, reusable template prepared September 17, 2026. It combines the content library and blank personal-brand scaffold with a tool-neutral qualification and conversation setup.

## Included sources

| Source | Treatment |
|---|---|
| GTM Architecture Kit, LinkedIn package revision `53c0a12` | Source of the portable skill library, blank context, synthetic buyer rubrics and initial workflow guides |
| content-vault | All 19 original top-level skills are represented, plus the nested Manim skill. These are portable adaptations; the mapping and exact source revisions are in the [skill catalog](../skills/README.md) and [manifest](../skills/catalog.json) |
| Blank content-engine template | Source of the author scaffold and context/brand skills, already included in the public consolidated library. No access to the original private repository is required |
| LinkedIn funnel artwork | PNG and editable Excalidraw. File hashes are in the [asset manifest](../assets/manifest.json) |

The content-vault adaptations retain each skill's purpose while removing old workspace-specific assumptions. They are not a verbatim archive of its original media helper programs. Apart from the bundled flowchart helper, media skills use tools available in the reader's environment.

## Validation and limits

Package checks cover skill discovery, local links, JSON, the blank context and asset hashes. Qualification examples are hand-authored, synthetic calibration cases; they do not demonstrate model accuracy. The prompt must be calibrated on your actual evidence and rubric.

No paid qualification run, automatic schedule or outreach was activated while packaging the template.

The [Notion guide](notion.md) includes the complete blank schema and setup prompt so readers can build a board in their own workspace.

The diagram is a detailed reference intended for zooming. The blank scaffold contains no inherited author claims, private campaigns, credentials or live connection IDs.
